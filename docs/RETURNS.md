# Returns and inspection

The prototype records an admin-received return for an allocated rental, then requires an inspection outcome for every allocated unit. Healthy units can re-enter availability; units needing cleaning, repair, or refurbishment enter maintenance; damaged or retired units remain unavailable.

No customer refund, cancellation charge, late fee, carrier collection integration, or automatic customer billing is implemented. Delivery/collection timestamps are shown only when persisted by an authorized operation.
